NETWORK
網路怎麼接，影片傳得最快
✓ 最推薦
電腦接網路線

手機用 Wi-Fi、電腦插網路線到路由器。影片在空中只走一段（手機→路由器），最快也最穩。

✓ 也可以
電腦和手機分開頻段

例如手機連 2.4 GHz、電腦連 5 GHz，兩邊不搶同一個頻道。如果路由器的兩個頻段是同一個 Wi-Fi 名稱，可以在路由器的設定裡分開。

✕ 盡量避免
  • 全部擠在同一個頻段影片要在同一個頻道上走兩次（手機→路由器→電腦），容易變慢、卡住
  • 訪客網路裝置之間通常被隔離，手機會連不到電腦
  • 電腦開著 VPN可能擋掉區網連線，請關掉，或開啟區域網路存取
兩台手機一起錄 4K 合計約 80 Mbps，手機越多需要的頻寬越大。錄影中傳不完沒關係，停止後會自動補完，控制台上看得到每台的傳輸速度。
