WHAT IT IS

多機錄影是什麼？

多機錄影（MultiCam Recorder）是一套免費、開源的多機位錄影工具，把手邊的 Android 手機變成可以同步錄影的攝影機。在電腦（macOS 或 Windows）上打開網頁控制台，就能同時看到每支手機的即時畫面、各自調整變焦，按一個鍵讓所有手機在同一刻開始錄影。影片在每支手機上用原生畫質錄，錄影中就一邊傳回電腦，停止後很快就能播放檢查。整個過程只用 Wi-Fi 區域網路，不需要雲端帳號，影片也不會上傳到網路。

USE CASES

適合哪些情境？

需要多個角度、又不想租攝影機和導播機的拍攝，都可以用手邊的手機搞定。

01

訪談、Podcast

主持人和來賓各一台，外接麥克風接在其中一台當主音軌，剪輯時隨時切換角度。

02

長影片＋短影音

一台橫拿錄 YouTube 用的 16:9，一台直拿錄 Reels、Shorts、TikTok 用的 9:16，一次錄好兩種版本。

03

課程、講座

一台在後面拍全景，一台在側邊拍講者和白板，講者走到哪都有畫面。

04

產品拍攝、開箱

正面、正上方俯拍、側面特寫同時錄，最多可以接 10 台手機。

FEATURES

功能特色

電腦負責指揮、監看和收檔，手機專心錄影。每一個細節都是為了「錄完馬上能用」。

錄影

一鍵同步開始

按 R 全部開始、S 全部停止。電腦先和每台手機對時，約好同一刻一起開始，清單上顯示實際的時間差。

手機原生畫質

4K、2K、1080p、720p 可選，所有手機一起套用。單段最長 30 分鐘，剩 3 分鐘網頁和手機都會提醒。

直式、橫式都能錄

手機橫拿錄 16:9、直拿錄 9:16，App 自動跟著轉，錄影中鎖住方向，不會錄成一半直一半橫。

外接麥克風

接上 USB 或耳機孔麥克風會自動改用它收音，App 和網頁都會顯示目前用的是哪一支。

監看

即時畫面

每台手機的畫面每秒約 5 張，用來確認構圖。按下開始錄影時監看區一律切回即時畫面。

各別變焦

常用倍率的按鈕加上滑桿，每台各自設定；有超廣角或望遠鏡頭的手機會自動換鏡頭。

構圖輔助框

在手機預覽、即時畫面和播放器上疊 9:16、4:5 或 1:1 的框，架機時就照最後要出的比例構圖。

狀態一目瞭然

每台的電量、溫度、剩餘空間、還能錄幾分鐘、傳輸速度；硬碟快滿、傳輸停住、手機斷線都會提示。

傳檔與整理

錄完馬上看

錄影中就邊錄邊傳，停止後只補最後一小段，再用 SHA-256 分段比對，確認和手機上的檔案一模一樣。

斷線也不怕

Wi-Fi 斷掉時手機照常錄影，連回來會自動續傳，影片不會遺失。

用專案整理

影片存進「錄影資料夾／專案名稱」，檔名是時間加手機名稱，同一段的檔案會排在一起。

標記與清理

星號標記好的段落，同一段的每台一起標；沒標記的一鍵移到垃圾桶，刪錯了也救得回來。

LONG-FORM + SHORTS

一次錄好長影片和短影音

一台橫拿錄 16:9 剪 YouTube 長片，一台直拿錄 9:16 剪 Reels、Shorts、TikTok。直接錄直的，不用從橫的畫面裁切：4K 直拿是 2160×3840，從 4K 橫畫面裁出來只剩約 1215×2160，畫素差了約 3 倍。

  1. 照想要的方向架好手機：App 會跟著手機轉，系統的「自動旋轉」關著也一樣；四個方向都可以，錄出來都是正的。
  2. 在控制台確認方向：直放那台的監看區會變成直的，下方寫著「即時畫面・直式 9:16」。
  3. 看即時畫面構圖：橫的那台可以開 9:16 輔助框，看看之後裁成直式時主角會不會出框；直的那台可以開 4:5 或 1:1，看 IG 貼文的範圍。
  4. 按 R 開始：每台的監看區都會切回即時畫面，錄影中方向固定，中途碰到手機也不會轉。
  5. 停止後馬上檢查：影片傳完會自動播放，直式影片直著播，清單上標「直式」；兩支錄的是同一段時間，剪輯時很好對齊。
HOW IT WORKS

運作方式

電腦是控制台

電腦上跑一個本機伺服器，同時提供網頁控制台。控制台只能在這台電腦上開，同一個網路的其他裝置打不開。

手機是攝影機

錄影在手機上進行（Camera2＋MediaRecorder），所以畫質不受 Wi-Fi 影響；Wi-Fi 只負責傳檔和控制。

檔案一模一樣

影片用 HTTP 分段傳回電腦，停止後雙方用 SHA-256 分段比對，不一樣的地方自動補傳，直到完全相同。

GET STARTED

三步驟開始使用

第一次設定大約 10 分鐘。之後每次只要在電腦執行 npm start、打開手機上的 App。

  1. 在電腦上安裝並啟動

    • 安裝 Node.js（選 LTS 版本，需要 24 以上），照安裝程式一路按下一步。
    • 下載程式：會用 Git 的話執行下面的指令；不會的話，到 GitHub 專案頁按綠色的 Code → Download ZIP 再解壓縮，然後跳過前兩行，改用 cd 進到解壓縮出來的 multicam-recorder-main 資料夾。
    • 打開終端機（macOS 是「終端機」App，Windows 是「PowerShell」），執行：
    git clone https://github.com/dean9703111/multicam-recorder.git
cd multicam-recorder
npm install
npm start

    看到 控制台：http://localhost:8787 就成功了。用瀏覽器打開 http://localhost:8787，畫面上的「開始使用」會帶你確認錄影資料夾（建議選外接 SSD）、配對手機、新增專案。npm install 只有第一次需要；要關掉時在終端機按 Ctrl＋C。

  2. 在手機上安裝 App，掃 QR Code 配對

    到 Releases 下載 MultiCamRecorder.apk 安裝（第一次會要你允許「安裝不明應用程式」）。接著在電腦網頁按「配對手機」，用手機相機掃 QR Code，在打開的網頁按「打開 App 並配對」就完成了。還沒裝 App 的話，掃完打開的網頁裡也有下載連結。每支手機只要配對一次。

  3. 新增專案，按 R 開始錄影

    • 在「專案」選單新增專案，影片會存進「錄影資料夾／專案名稱」。
    • 在「錄影規格」選解析度（4K、2K、1080p、720p）和構圖輔助框。
    • 按 R 所有手機一起開始、S 一起停止；停止後影片傳完會自動在監看區播放。
    • 錄影時 App 要一直開在前景，螢幕不能關；長時間錄影可以按 App 上的「調暗螢幕」。

更完整的說明（播放、標記、移到垃圾桶、疑難排解）都在 GitHub 的 README。

PHONE APP

手機 App：架好之後就不用再碰它

開始和停止都由電腦控制。App 畫面上清楚顯示連線狀態、錄影計時、收音來源、變焦倍率和傳輸進度；直拿時畫面也會跟著轉直。

NETWORK

網路怎麼接，影片傳得最快

  • 最好讓電腦接網路線：每支手機的影片在空中只要走一段。
  • 或讓手機和電腦分開頻段：例如手機連 2.4 GHz、電腦連 5 GHz，兩邊不搶同一個頻道。
  • 不要用訪客網路：裝置之間通常被隔離，手機會連不到電腦；開著 VPN 也可能連不到。
  • 兩台都錄 4K 時合計約 80 Mbps。錄影中傳不完沒關係，停止後會自動補完。

FAQ

常見問題

多機錄影要付費嗎？

不用。多機錄影是 MIT 授權的開源軟體，電腦端和手機 App 都免費，沒有廣告，也不用訂閱或註冊帳號。

可以用 iPhone 嗎？

目前只有 Android 12 以上的 App。電腦和手機之間的通訊格式是公開的（server/protocol.ts），其他平台照著實作就能接上。

電腦端支援 Windows 嗎？

支援。每次更新程式，GitHub Actions 都會在 Windows、macOS、Linux 上用兩支模擬手機把配對、即時畫面、同時錄影、傳檔和驗證整個流程跑一遍。實際使用的是 Apple Silicon 的 Mac，Windows 還沒有人用實機錄過，遇到問題歡迎開 issue。

需要網路嗎？影片會上傳到雲端嗎？

不會上傳到雲端。錄影和傳檔只在你的手機和電腦之間進行，走同一個 Wi-Fi 的區域網路，不需要任何帳號；影片存在電腦上你選的錄影資料夾。只有第一次下載程式和 App 時需要上網。

錄影畫質會受 Wi-Fi 影響嗎？

不會。影片是在手機上用原生畫質錄的，Wi-Fi 只負責傳檔和控制；Wi-Fi 慢的時候只是傳得比較久，停止後會把剩下的補完。

和把手機畫面串流到電腦（例如當成 OBS 的攝影機）有什麼不同？

串流的做法是把畫面即時傳到電腦，畫質會受網路影響，適合直播。多機錄影是在每支手機上錄原生畫質，再把檔案傳回電腦，適合錄完要剪輯的拍攝；它沒有直播功能。

最多可以接幾支手機？

10 支。手機越多，Wi-Fi 頻寬需求越大，兩台 4K 一起錄合計約 80 Mbps，請參考網路設定。

可以同時錄直式和橫式嗎？

可以。手機直拿就錄 9:16、橫拿就錄 16:9，同一次錄影裡可以混著用，例如一台錄長影片、一台錄短影音，做法請看這一節。

多支手機錄的影片怎麼對齊？

電腦會先和每支手機對時，約好同一刻開始，清單上會顯示各台實際的開始時間差。要精準到同一格畫面，建議用剪輯軟體依音訊自動同步。

可以用外接麥克風嗎？

可以。手機接上 USB 或耳機孔麥克風時會自動改用它收音，App 和電腦網頁都會顯示目前用的是哪一支。

怎麼更新到新版？

手機下載新的 MultiCamRecorder.apk 直接安裝，會覆蓋舊版，配對和設定都會保留；電腦在專案資料夾執行 git pull，再重新 npm start。
